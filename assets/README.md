### `dashboard_overview.png`

Overview screenshot of the dashboard used during the competition for strategy diagnostics.

The dashboard was used to inspect:

- spread distributions by day,
- price paths and trade markouts,
- visible PnL paths,
- product-level behaviour across trading days,
- differences between strategy versions.

This image is included to show the dashboard-driven analysis workflow used during the competition. The dashboard helped us move faster than notebook-only analysis when comparing strategies under time pressure.
